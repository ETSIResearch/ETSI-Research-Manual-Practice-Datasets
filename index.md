# ETSI Research Manual Practice Datasets

Download the CSV files used in the practice analyses and demonstrations in the ETSI Research Manual. Each file can be opened in JASP or a spreadsheet program. No account is needed to download the files.

## Download all datasets

<a href="all_practice_data.zip" download>Download all 14 practice datasets (ZIP)</a>

Extract the ZIP file before opening the CSV files in JASP.

## Download individual datasets

Files are listed in chapter order. Datasets used in more than one chapter are listed once, with all relevant chapters indicated.

## Using the files

Download the file named in your exercise, save it somewhere you can find again, and open it in JASP. Keep an unchanged copy of the original file when saving your own work.
